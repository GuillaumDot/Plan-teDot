# V1.2 Contextual chemistry
Public inspiration: https://store.steampowered.com/app/2198150/Tiny_Glade/ and developer announcements https://store.steampowered.com/news/posts/?enddate=1682596332&feed=steam_community_announcements . Original implementation, not game source.
## Implemented
Segment intersections -> gate/lintel/arch descriptor, wide opening pillar flag, sampled water crossing -> bridge span, steep path -> stair count, terrain sampled foundations, humid mature buildings -> ivy coverage. Pure deterministic function; no scene mutation. Descriptors are not geometry. Local planar coordinates in consistent metre-like units, supplied by native adapter. Do not pass spherical longitude directly.
## Integration
Keep native seed and progression, use local tangent frame and terraH-equivalent CPU sampler (validate against shader). Resolve only active visible chunks on topology/stage changes; cache by stable chunk id + terrain revision + stage bucket. For large chunks spatially bin walls and paths before calling; current implementation pairwise O(w*p). No per-frame calls. Keep disabled for atmosphere-only worlds. Translate descriptors to native lot97/roof97/wall97 or local geometry overlay; trim walls at openings and generate actual arch geometry and collision-free supports. Merge overlapping openings before rendering. Bridge sampling can miss narrow water; refine with native shoreline intersections. Stairs use endpoint slope only: subdivide curved paths. Foundation samples require interior checks for irregular ground. Never alter saved planet data. Validate units and GPU budget before enabling.
## Next rules (design only)
Window merging and facade rhythm, roof junction flashing, shared walls, retaining walls, road routing around steep slopes, terrain-aware vegetation exclusion, snow accumulation on roofs, wetness at wall bases, erosion and ivy masks, riverbank transitions, docks at navigable shores. Priority: terrain/water -> access -> structural support -> openings -> envelope -> decoration -> FX. Maintain stable ids; use local invalidation, hysteresis, and LOD. Do not imitate game assets or copy game code.
