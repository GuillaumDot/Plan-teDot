# V1.7 — Volumetric Atmosphere
Prototype GLSL ES 3.00 original, inspiration visuelle fumée AAA, pas de code RAGE. Quatre champs de densité 3D : nuages, bandes gazeuses, spectres émissifs, panaches locaux. Bruit fractal déformé, advection analytique, extinction Beer-Lambert, auto-ombrage approximatif à deux sondes, composition prémultipliée. Pas de simulation fluide ni de diffusion multiple physique.
Intégrer sur branche laboratoire, flag off. Appeler pd17March depuis une passe native à résolution réduite, rayon et soleil normalisés, temps monotone en secondes, seed stable borné, tint linéaire. Calculer intersection sphère externe puis couper à la profondeur opaque (terrain, bâtiments), ne jamais traverser le sol. Panaches : coordonnées locales Y-up, boîte bornée, transformer rayon et lumière dans ce repère; ancrer aux cheminées/volcans existants. Le gaz utilise une couche externe autour du corps natif, pas une planète entièrement volumétrique. Spectres : émission douce sans flash. Réutiliser le cache et le RAF existants. Pas de modification des seeds, XP, audio ou sauvegardes.
Qualité : 8/12/20/32 pas, échelle de rendu .5/.5/.67/.75, maximum 1/2/4/6 panaches visibles; budgets indicatifs, pas mesurés. Au loin conserver les masques V06/V07. Ne pas superposer les deux rendus au même endroit. Pour jitter utiliser un motif stable par pixel; si accumulation temporelle native disponible, rejeter historique lors des mouvements/occlusions; sinon éviter jitter animé. Composition linéaire avant tone mapping, upscale guidé par profondeur si disponible. Tester halos, scintillement, caméra dans couche, nuit, transparence, export vidéo, mémoire et thermique iPhone. Shader non compilé dans le moteur; vérifier compatibilité WebGL2 et fallback WebGL1 natif. Les nuages ne projettent pas encore d'ombre sur le terrain : prévoir une approximation native optionnelle.
