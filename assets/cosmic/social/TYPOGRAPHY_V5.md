# V5 — Living Typography
Module facultatif, conserve V4. Appeler typography(kind, age, options) depuis la boucle native, avec age en ms depuis l'événement. Les textes du catalogue sont des suggestions : conserver le message préenregistré exact validé par le serveur si différent. Utiliser textContent, jamais innerHTML. Le variant stable peut provenir du hash de l'identifiant événement. Aucun changement de données ni de réseau. Appliquer les propriétés CSS via le moteur UI existant, sans nouvelle RAF. Ancrer au-dessus de la tête projetée ou du sprite; utiliser visibilité et occultation natives; masquer derrière la planète, décaler dans la zone sûre et éviter les chevauchements (priorité à la réaction la plus récente). Ne pas afficher plus de trois labels. Le texte reste lisible de nuit via contraste local; couleur de lueur adaptée au climat, sans assombrir le texte comme un objet physique. Pour export vidéo, dessiner le même texte via le compositeur natif plutôt que supposer que le DOM est capturé. Les styles sont des paramètres, pas un moteur de typographie 3D. Respecter reducedMotion et ne pas déclencher de flash. Tester Safari iPhone, zoom, rotation, export, contraste et textes longs avant fusion.
