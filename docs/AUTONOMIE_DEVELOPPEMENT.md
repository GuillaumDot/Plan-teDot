# Directive de développement
Le propriétaire définit le résultat artistique et fonctionnel. Les assistants choisissent les moyens techniques, réalisent les modifications réversibles, testent et documentent sans demander de validation intermédiaire inutile. Préserver les données, secrets, audio et versions fonctionnelles. Solliciter le propriétaire uniquement pour une intervention indispensable, une dépense ou une décision irréversible. Ne jamais déclarer une réparation validée sans preuve. Priorité actuelle : planètes invisibles sur iPhone, y compris après restauration V9.8 signalée par le propriétaire; version effectivement servie non confirmée. Diagnostiquer avant nouvelles intégrations, tester sur branche laboratoire et préserver les ressources existantes.
